History Rhymes

Today's news, and the last time it happened.

Front page

What this is

Pick a news story and History Rhymes finds an event from the past that followed the same pattern, then writes a two-minute lesson about it, illustrated with stick figures. Every lesson ends with where the comparison stops working, because no two events are the same.

How a lesson is made

  1. Headlines. Top stories are pulled from NewsAPI every hour, and a language model keeps the ones with some depth to them (power, money, conflict, disease, institutions) and drops sport, celebrity and the like.
  2. Candidates. Two searches run at once. One is a semantic search over an archive of several hundred thousand Wikipedia history articles, embedded with OpenAI's text-embedding-3-small and stored in Pinecone. The other is a Claude agent with live web search, asked for three parallels.
  3. The choice. A second agent weighs the candidates. If none is good enough it can search again, this time describing the underlying mechanism (say, “a creditor state forcing austerity on a debtor”) instead of the headline's words, which tends to retrieve much better parallels. It gets two rounds.
  4. The lesson. A writer model turns the choice and the source material into sections, each with a scene description: who is in it, how they stand, what props are around, what they say. Your browser draws the scene from that description; no image model is involved, which is why every drawing looks the same.

Each lesson page has a “How this lesson was made” note listing the alternatives considered, the sources retrieved, and the time and cost.

Is it any good?

The retrieval step is measured against a labelled test set; the method and results are in the eval/ directory of the source code.

Caveats

The lessons are written by a language model. It is instructed to stick to well-documented facts and to leave out anything uncertain, but it can still be wrong. The sources are listed so you can check.

Built with Claude, OpenAI embeddings, Pinecone and FastAPI.
